# Atualizacao_Limpeza.bat
Criar o Script de Atualização e Limpeza

Para criar um arquivo .bat de atualização do Windows, abra o Bloco de Notas, cole os comandos wuauclt /detectnow e wuauclt /updatenow, salve como "Atualizacao_Limpeza.bat
" (selecionando "Todos os Arquivos") e execute-o como administrador. Este script força a detecção e instalação de atualizações pendentes no Windows Update

Criar um arquivo .bat (Batch) para limpeza do Windows automatiza a exclusão de arquivos temporários, liberando espaço em disco. O processo envolve abrir o Bloco de Notas, colar comandos de exclusão (del, rd), salvar com a extensão .bat e executar como Administrador para maior eficácia.
